# Library System

## Description

Library System adalah aplikasi sederhana berbasis Laravel yang digunakan untuk mensimulasikan sistem informasi perpustakaan. Project ini dibuat sebagai tugas Pertemuan 4 pada mata kuliah Pemrograman Web Framework.

## Requirements

Sebelum menjalankan project, pastikan sudah tersedia:

- PHP
- Composer
- MySQL
- Laravel
- Git
- Web Browser
